# TaxonMech

Knowledge base of microbial taxa and the strains behind them — NCBI Taxonomy
identity harmonized with GTDB, LPSN and BacDive, seeded from
[kg-microbe](https://github.com/Knowledge-Graph-Hub/kg-microbe)'s transforms.
One of the CultureBotAI Mech repositories; follows the pattern of
[dismech](https://github.com/monarch-initiative/dismech).

## 2. Detailed Remediation Notes for Cycle 2 Stage 5 Resolved Group

### 2.1 `group-structured-inventory-target-sha256-reconciliation` ([#158](https://github.com/CultureBotAI/TaxonMech/issues/158), [#78](https://github.com/CultureBotAI/TaxonMech/issues/78))

- **Root Cause**:
  1. In Cycle 2 Stages 2–3 (PRs `#155`, `#156`), 15 `TaxonRecord` YAML files in `data/taxa/` were legitimately updated via `curation/causal_graphs/NCBITaxon_*.yaml` and `src/taxonmech/seed.py`. Ten of those 15 records belong to `docs/structured-review-inventory/part-{02,05,08,12,13}.tsv` (`NCBITaxon:1423`, `NCBITaxon:224308`, `NCBITaxon:562`, `NCBITaxon:83333`, `NCBITaxon:511145`, `NCBITaxon:287`, `NCBITaxon:208964`, `NCBITaxon:2190`, `NCBITaxon:243232`, `NCBITaxon:1859096`). Although their updated YAML SHA-256 digests were re-reviewed and pinned in `reviews/structured/20261022T190800Z-cycle2-stage3-uniprot-protein-examples/review.yaml` (and `20261023T073200Z-cycle2-stage4-corpus-record-review/review.yaml`), `load_structured_shards(..., verify_target_sha256=True)` in `scripts/corpus_review_inventory.py` compared current worktree hashes solely against the static `target_sha256` column in `part-*.tsv`.
  2. `verify_shard_bundles(..., verify_target_sha256=True)` in `scripts/corpus_review_inventory.py` enforced `inp["sha256"] == sha_cache[rel_inp]` across every `role: target` input in every historical bundle under `reviews/structured/*/review.yaml`, contradicting `scripts/record_review.py`'s append-only immutability contract (`Historical reviews remain valid observations when records later change`).
- **Native Writer Fixes**:
  - Added `load_latest_target_reviews(root: Path)` in `scripts/corpus_review_inventory.py` to scan `reviews/structured/*/review.yaml` for valid scientific review bundles (`scientific_review: true`, `completion in {"completed", "partial"}`, `verdict in ALLOWED_VERDICTS`) and record the latest `(finished_at, review_id, sha256, bundle_yaml)` per `(target_id, path)` and per `path`, rejecting ambiguous equal `finished_at` timestamps with differing hashes.
  - Updated `load_structured_shards()` so when `verify_target_sha256=True`, each shard row's expected `target_sha256` reconciles against `latest_by_target[(target_id, path)]` whenever `(bundle_finished, bundle_review_id) > (row_finished, row_review_id)`.
  - Updated `verify_shard_bundles()` so when `verify_target_sha256=True`, a `role: target` input in an older append-only bundle that has been strictly superseded by a newer scientific review bundle in `latest_by_path[rel_inp]` is preserved as an immutable historical snapshot, while the latest bundle for each `role: target` path must match `sha_cache[rel_inp]`.
  - Added regression test `test_curated_target_reconciled_by_newer_structured_review_bundle` in `tests/test_corpus_review_inventory.py` covering post-curation failure prior to re-review, reconciliation after saving a newer follow-up review bundle, and failure if the record is subsequently modified or reverted without a newer review bundle.
